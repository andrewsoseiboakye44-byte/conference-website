Gateway Setup Quick Guide

Arkesel / Hubtel / mNotify

Select provider, enter your registered Sender ID (e.g. your Church Name), and paste your API Key from your provider dashboard.

Africa's Talking

Enter your registered Sender ID, your Africa's Talking API Key, and enter your Africa's Talking Username in the second field.

Any Custom Provider

Select "Custom SMS Gateway", paste their HTTP endpoint with query or body tokens, input your API Key and start sending instantly.
